# Open Monknow v0.1.1 · 自在新标签

首个公开 Release：无广告、数据保存在本地的 Chrome 新标签页。与 MONKNOW 官方无关联，代码采用 MIT，网站图标的许可单独列明。

## 包含什么

- 搜索和直接打开网址：Google、Bing、百度、DuckDuckGo。
- 分组网址、拖动排序、跨组移动，以及编辑、删除和撤销。
- 本地时钟、日期、壁纸和待办；JSON 备份与恢复。
- 字体、图标和间距随窗口大小缩放，设置中可额外放大 15% / 30% / 50%。
- 常用网站内置图标，其他网站使用 Chrome favicon，也可选择文字图标。
- 仅申请 `storage` 和 `favicon` 权限，没有账号、广告统计或云同步。

## 下载与安装

1. 下载附件 **[open-monknow-0.1.1.zip](https://github.com/burun/open-monknow/releases/download/v0.1.1/open-monknow-0.1.1.zip)** 并解压。
2. 打开 `chrome://extensions`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择 **直接包含 `manifest.json` 的 `open-monknow` 文件夹**。
4. 新开标签页并保留 Chrome 的新标签页更改；若另一个扩展仍在接管，将它停用。

需要 Chrome 120+，无需 Node.js 或编译。不要直接加载 ZIP。完整中英文步骤见附件 **[INSTALL.md](https://github.com/burun/open-monknow/releases/download/v0.1.1/INSTALL.md)**，ZIP 内也有同一份说明。

**已有安装：** 先导出备份，在原路径替换文件，再到扩展管理页「重新加载」。不要卸载后重装。如果提示新增 `favicon` 权限，允许即可。分组、网址、待办和设置会保留。

## 验证和已知边界

发布流程检查版本号与 Git 标签一致，执行资源/文档检查、11 项单元测试和构建。此前真实扩展验证覆盖核心交互、旧数据、备份、离线加载、五种窗口尺寸和手动缩放，详情见 [验证记录](https://github.com/burun/open-monknow/blob/v0.1.1/docs/validation.md)。

界面目前主要为中文；不提供天气、账号、跨设备云同步或原 MONKNOW 专有格式迁移。浏览器未缓存某个网站图标时可能显示默认图标。卸载会删除浏览器中的插件数据，请先导出备份。
