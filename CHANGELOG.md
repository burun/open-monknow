# Changelog

## Unreleased

- Prepare the repository for open-source distribution with bilingual READMEs, contribution, privacy, security, development, and licensing documentation.
- Add continuous integration for resource checks, unit tests, and build validation.
- Remove the bundled Are.na favicon, whose redistribution license was not established; use Chrome's favicon resource instead.
- Add a reproducible browser-test runner with isolated profiles and generated test fixtures.

## 0.1.1 — 2026-10-19

- Increase default text sizes and scale typography, icons, and spacing with the viewport.
- Add optional extra interface scaling of 15%, 30%, or 50%.
- Add bundled common-site icons, Chrome favicon support, and a per-shortcut text-icon option.
- Preserve older saved data and backups with defaults for new settings.
- Add the `favicon` permission; Chrome may request approval on reload.

## 0.1.0 — 2026-10-19

- Initial local-first Chrome Manifest V3 extension.
- Search, grouped shortcuts, drag and drop, clock, local wallpapers, and to-dos.
- Themes, responsive layout, validated JSON backups, and undo for common deletions.
